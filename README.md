# Ashwani Kumar 'Bheem' — Portfolio (React + Tailwind CSS + Vite)

    npm install
    npm run dev       # local preview
    npm run build     # production build in /dist (works on GitHub Pages)

Edit content in `src/data.js` (books, journey, craft, contact). Replace book covers/photo in `src/assets/` (same file names).
Sections live in `src/components/`; shared pieces (Section, Pill, Tag) in `src/components/ui.jsx`.
